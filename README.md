# Полка — читалка FB2 и EPUB

Веб-читалка для телефона и компьютера. Книги открываются с устройства и хранятся только в браузере пользователя (IndexedDB), никуда не отправляются.

## Возможности (версия 0.2)

- FB2, FB2.ZIP и EPUB, включая кодировку windows-1251
- Постраничный режим и прокрутка, запоминание места
- Оглавление, сноски во всплывающей панели, ползунок по книге
- Закладки и поиск по всей книге с подсветкой
- Темы, включая E-ink; шрифты, размер, интервал, поля, переносы
- Установка на телефон как приложение и работа офлайн

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `polka`.
2. Загрузите в корень все файлы из этой папки: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `.nojekyll`, `README.md`.
3. Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/polka/`.

## Обновление

Замените `index.html` новой версией и увеличьте `VERSION` в `sw.js` (например, `polka-0.3.0`). Без этого у пользователей может остаться старая версия из кэша.

## Установка на телефон

- Android (Chrome): меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- iPhone (Safari): кнопка «Поделиться» → «На экран „Домой“».
